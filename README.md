# 退化几何作图验算台

面向在校学生的平面几何作图与验算工具：用**点、直线、圆、交点和约束**搭出作图链，
拖动自由点时**实时重算所有后继图元**，并**逐步解释**平行、相切、重合、无交点等退化情形
如何让待证关系**成立 / 失效 / 变为未定义**。

- 纯原生 HTML + CSS + JavaScript + SVG，**无任何外部依赖，断网可用**
- 几何内核运行在 **Web Worker**，主线程按**修订号（revision）**只接纳最新结果
- 三值结论：**成立 / 不成立 / 未定义**（+ 结构版本失配 stale）
- 浮点判定采用**严格带 1e-9·S 与接近带 1e-6·S 双阈值**，接近绝不冒充成立
- 删除图元列出完整**级联影响**，删除为原子事务，可一键**撤销整体回滚**
- JSON 保存 / 导入：拓扑排序归一化 + 约束参数重吸附，**缩放、点序变化不影响判定**

## 运行

直接用浏览器打开 `index.html` 即可（无需服务器、无需联网）。

> 若以 `file://` 打开且浏览器禁止本地 Worker，程序会自动降级为同内核同步计算，
> 判定逻辑完全一致。如希望强制使用 Worker，可在本目录执行
> `python3 -m http.server 8000` 后访问 `http://localhost:8000/`。

## 操作指南

| 操作 | 方式 |
| --- | --- |
| 添加自由点 | 点选“自由点”后在空白处单击；或在默认状态下直接单击空白 |
| 约束点（在线/圆上） | 点“约束点”，再单击直线或圆；拖动时沿宿主滑动 |
| 直线/平行线/垂线/圆/中点 | 点工具按钮，按顶部横幅提示依次选点（或点+线） |
| 交点 | 点“交点”，选两条直线、直线与圆或两圆；相切时自动只保留唯一切点 |
| 待证关系 | 右栏上方按钮，按提示选择对应数量的图元 |
| 拖动 | 直接拖自由点（实心蓝）/约束点（实心绿），后继实时重算 |
| 缩放/平移 | 滚轮缩放，拖空白处平移 |
| 删除 | 图元列表右侧 ✕；弹出级联清单，确认后原子删除 |
| 撤销 | Ctrl/⌘+Z 或顶部按钮（结构操作、每次拖拽均为一个事务） |
| 保存/导入 | 顶部按钮，JSON 文本文件，可跨设备交换 |

## 判定规则（关键取舍）

1. **严格容差带** ε = 1e-9·S（角度 1e-9 rad）：差值落入此带才允许数值判“成立”，标注“数值判定”。
2. **接近提示带** 1e-9·S ～ 1e-6·S：判为“不成立（接近）”，给出差值，**绝不冒充成立**。
3. **由构造保证**：平行线复制方向向量、垂线旋转 90°、同圆半径、中点平分、
   半径端点垂线切线、反向角等，由作图定义直接成立，标注“由构造保证”，不做浮点比较。
4. **退化即未定义**：平行不同线、重合直线/圆、无交点（直线远离圆、圆分离/内含/同心异径）、
   零半径、零长度比较量等，交点与后继关系逐级标为未定义，解释面板按依赖链展示每一步。
5. **构造版本绑定**：待证关系创建时绑定基于“彩色细化”的结构签名（与坐标、缩放、对象顺序无关）。
   作图结构改变后旧关系标为“版本失配”，不会自动套用到新构造。

## 文件结构

```
index.html          界面
css/style.css       样式
js/kernel.js        几何内核（纯逻辑，Worker/Node 共用）
js/worker.js        Web Worker 包装（修订号消息协议）
js/main.js          主线程：SVG 渲染/拖拽/撤销/删除/导入导出/修订闸门
tests/test_kernel.js 内核与判定规则测试（60 项）
tests/test_worker.js Worker 修订闸门乱序实跑测试（9 项）
```

## 自动化检查

```bash
npm test         # 或：
node tests/test_kernel.js
node tests/test_worker.js
```

覆盖：作图链搭建、拖动后继重算、平行/相切/重合/无交点三值判定、双阈值取舍、
级联删除与回滚、缩放/点序导入一致性、构造版本失配、Worker 迟到结果丢弃。
